# TofuCraft for NeoForge 26.1

A Minecraft mod that adds tofu-based content, Japanese food items, a custom Tofu dimension, and much more.

Ported from Minecraft 1.7.10 to NeoForge 26.1 (Minecraft 26.1).

## Features

- Multiple tofu block variants with unique properties
- Japanese food items (miso, soy sauce, natto, etc.)
- Custom Tofu dimension with unique biomes
- Tofu-themed mobs (Tofu Slime, Tofu Creeper, Tofunian)
- Tofu Force energy system with machines
- Tofu tools, armor, and weapons
- Salt production system
- Fermentation mechanics

## Dependencies

- NeoForge 26.1.0.0+
- Minecraft 26.1
- Java 21+

## Building

```bash
./gradlew build
```
